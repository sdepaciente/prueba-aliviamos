Esta herramienta contiene información de pacientes. Solicita la clave de acceso a la coordinación de calidad y seguridad del paciente. Buscar informe de oximetría

Cada paciente tiene un único informe, identificado por su número de documento — igual que un número de historia clínica. Escriba el documento del paciente para abrir su registro (o crear uno nuevo si es la primera vez) — solo se muestra la información de ese paciente, no la de otros. Los datos se guardan automáticamente en la nube y el informe en Word se actualiza solo después de cada medición.

Configuración pendiente: falta conectar este archivo con tu backend de Google Apps Script. Reemplaza APPS_SCRIPT_URL al inicio del script por la URL de tu Web App (ver instrucciones entregadas junto con este archivo) y vuelve a publicar el archivo en GitHub Pages.

Si el paciente ya tiene un informe, se abre con todo lo registrado hasta ahora. Si es la primera vez, se crea uno nuevo con ese documento.
